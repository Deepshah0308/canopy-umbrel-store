# Install Canopy

No terminal needed. You only add the store once; after that, Canopy's apps show up in Umbrel's App Store next to the official ones.

## Updates

Canopy checks every app for new releases each morning, tests them, and ships them. Umbrel then shows an **Update** button on the app, the same as for official apps.

## Removing Canopy

Uninstall any Canopy apps you no longer want, then in **App Store → ⋯ → Community App Stores** remove Canopy's address.
